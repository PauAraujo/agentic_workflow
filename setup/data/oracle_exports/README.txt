Oracle schema exports (generated by export_oracle_schema.py).

Each subdirectory is one schema (e.g. ICSR_LOOKUP/) and contains:
  - _metadata.json   Schema structure (tables, columns, constraints, FKs, indexes)
  - *.csv            Sample data (first 1000 rows per table)

To populate:
  python setup/export_oracle_schema.py --target-schema ICSR_LOOKUP

This data is consumed by:
  - generate_table_cards.py  (reads _metadata.json to build table cards)
  - generate_ddl.py          (reads _metadata.json to produce DDL scripts)
  - build_sqlite_from_exports.py (reads CSVs to build local SQLite DBs)
  - load_csv_to_oracle.py    (reads CSVs to load data into a new Oracle instance)
